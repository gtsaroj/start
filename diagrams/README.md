## 🚀 How to Export as Images

### Step 1: Open File
- Open any `.mmd` file (e.g., `01-system-architecture.mmd`)

### Step 2: Copy All Content
- Press `Ctrl+A` (select all)
- Press `Ctrl+C` (copy)

### Step 3: Paste into mermaid.live
1. Go to [https://mermaid.live](https://mermaid.live)
2. **Delete** everything in the left panel
3. Paste your copied code (`Ctrl+V`)
4. Diagram will render on the right ✅

### Step 4: Download
- Click **"Actions"** button (top right)
- Choose **"Download PNG"** or **"Download SVG"**
  - PNG = Good for presentations/Word docs
  - SVG = Best quality, scalable for reports

### Step 5: Rename
- Save with descriptive name:
  - `smarthire-system-architecture.png`
  - `smarthire-user-journey.png`
  - etc.
